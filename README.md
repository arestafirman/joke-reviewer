A tiny Node 22 program (standard library only, no network) that writes a single one-line joke about working beside an AI coding agent to `/output/entry.txt`.

Run it with `node main.ts`; set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
